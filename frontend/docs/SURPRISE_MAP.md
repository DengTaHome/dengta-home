# 沿途来信地图

2026-10-16，本地实现；没有推送、部署、执行生产迁移或构建新 APK。

## 浏览

侧边栏 → 藏宝地图。默认保留本地方位图，不调用定位、不读取地图服务器。

点击“本次开启街道地图”，按当前可见区域从 OpenStreetMap 标准底图服务读取图片。支持拖动、双指缩放、放大/缩小、查看全部信件范围；点击信件圆圈或列表中的“查看这封信的范围”，选中对应模糊区域。选中不等于领取，领取仍需重新定位并由灯塔后端验证距离。

第三方底图服务可得到客户端 IP、当前查看区域、浏览器来源等网络信息。请求不包含信件文本、账户 ID、令牌或精确 GPS 回执；本次定位用于地图居中时先取整到经纬度 0.01 度（尺度随纬度变化），不绘制精确 GPS 点。信件范围使用服务端已模糊的坐标。没有把模糊范围描述成实际落点或可用于导航的地址。

在线底图授权只保留到离开此功能或切换账号/伴侣，不写入长期设置；关闭后销毁地图。页面隐藏或地图离屏时移除底图层，恢复可见时按浏览器 HTTP 缓存加载；没有离线下载、批量抓取、预加载城市或后台地图请求。

## 错误

- `map_tiles_unavailable`：至少一张底图图片加载失败，可关闭在线地图继续用方位图与信件列表。
- `map_tiles_timeout`：18 秒未完成加载，可关闭后重新开启。
- `map_display_failed`：地图代码加载或初始化失败，可关闭后重试。
- `surprise_map_receipt_invalid`：信件 ID、坐标、半径或已领取正文无效，保持原草稿并提示核对回执。
- `surprise_map_schema_required`：灯塔服务端缺少已有地图功能表，浏览器增加底图不会替代数据库安装。

底图为外部服务，网络、地区访问和限流仍可能失败。实现中不默认重试风暴，不绕过缓存；实际供应商访问与 Android 真机未验收。

## 数据与许可

私人信件、当前账号/伴侣隔离、明确确认公开版本、领取和撤回仍走原接口与 RLS 草稿，不更改提示词、人设或用户数据。地图代码在用户开启时动态加载，避免把 Leaflet 放进首屏包。

地图组件：[Leaflet 1.9.4](https://leafletjs.com/)，BSD-2-Clause，完整声明包含在 `public/licenses/leaflet.txt`，随网页及未来 APK 分发。原生 WebView 保留默认浏览器 User-Agent 并附加 DengTaHome 标识。

地图数据与标准底图遵循 [OpenStreetMap tile policy](https://operations.osmfoundation.org/policies/tiles/)；地图中始终展示 OpenStreetMap 署名。生产规模增加时应换用具有相应容量与授权的底图服务，当前没有接入高德商业 SDK，也没有从其他地图 App 提取离线包。

## 本地验证范围

`npm run test:surprise-map` 覆盖真实组件操作、坐标与回执、定位授权、保存重放、公开版本确认、迟到回执、地图初始化/销毁、离屏/后台暂停与错误事件。浏览器检查使用真实 Leaflet，但所有底图请求都由本地虚构图片拦截，未访问 OSM、未定位真实用户；不能据此宣称外部底图已在生产或手机通过。
