# DengTa Home · 灯塔的家

DengTa Home 是面向成年用户的 AI 陪伴应用，围绕持续对话、个性化角色、长期记忆与共同活动构建。用户可以配置模型供应商，保存自己的个性化指令与伴侣档案，在聊天、日记、音乐、观影和创作中积累连续的关系体验。

项目提供 React 网页/PWA 与 Capacitor Android 客户端，配套 Node.js/Express 后端和 Supabase 数据层。语音、外部记忆、MCP、音乐和视频能力依赖用户授权、相应服务配置及设备支持。

## English

DengTa Home is an AI companion app for adults, built around continuous conversation, personal characters, long-term memory, and shared activities. Users configure their model providers and shape their companions through personal instructions, profiles, chats, diaries, music, watch sessions, and creative work.

The project includes a React web/PWA client, a Capacitor Android app, and a Node.js/Express backend with Supabase. Optional voice, memory, MCP, music, and video features depend on the configured services, user permissions, and device capabilities.
