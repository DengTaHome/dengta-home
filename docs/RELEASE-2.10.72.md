# DengTa Home 2.10.72 · 灯塔少女与动态海岸

采用用户选定的原创灯塔少女图标，统一网页、PWA 和 Android 资源，并优化自适应图标扩边。

新增白天、晨昏、夜晚三段无声海岸循环，海浪轻动、夜间灯光扫动。三个视频合计 967147 字节；减少动态、省流、低电量、自定义壁纸或隐藏时停止或释放视频。彩虹胶囊、彩色气流、原日记背景与太阳/月亮算法保留。

修复暴雨模式只有闪电、遗漏雨滴和乌云，以及连续切换日夜时短暂使用旧海报的问题。
