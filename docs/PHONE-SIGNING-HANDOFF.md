# 给用户：现在要签什么、以后如何用全能签

**现在没有需要你签名的文件。** 当前交接的是源码、报告和测试证据，还没有构建出可安装到 iPhone 的设备版 `.ipa`，也没有设备版 `.xcarchive`。

ZIP、JS、Swift、截图、补丁、模拟器 App 都不用签。模拟器专用的临时 ad-hoc 签名不适用于 iPhone，不能把模拟器 App 改成 IPA 交给你安装。

## 你现在只需要做这件事

下载交接包，把 ZIP 和 `LOCAL-GPT-HANDOFF.md` 一起交给你电脑里的 AI。你不必知道 D 盘具体目录；让它自行定位工作区，在隔离副本中导入。可以直接转发下面这段话：

> 请先阅读 LOCAL-GPT-HANDOFF.md，定位我现有的工作区，不要猜测目录或覆盖原文件。检查本地版本与交接源码的差异，继续完成原生 Keychain/模拟器启动阻断、自动 UI/快照测试，再通过 Mac 或 GitHub macOS runner 构建设备版 Release IPA。我使用全能签，签名放最后。请把真正的设备 IPA 发给我，并用大白话告诉我该怎么导入；不要让我签源码或模拟器文件。

## 本地 AI 生成真正 IPA 后

1. 把 AI 给你的 `.ipa` 保存到 iPhone 的“文件”App。
2. 通过分享菜单导入全能签，或在全能签内选择“导入文件”。不同版本按钮名称可能略有差别。
3. 在全能签选择已有的有效签名证书和对应描述文件。若没有，先让本地 AI说明可用方案；安装了签名软件并不代表已经有证书。
4. 选择这个 IPA，按本地 AI 给出的包标识和权限设置进行签名，再安装。保留同一包标识和账号，避免续签时丢失 Keychain 访问权限。
5. 若 iOS 提示信任开发者或启用开发者模式，按照系统提示完成，再打开 App。

证书/描述文件应由你在自己的工具中管理，不需要在聊天中发送 Apple ID 密码、证书私钥或解锁密码。

## 关于 7 天和应用数量

免费 Apple ID 的个人开发签名渠道通常需要每 7 天刷新，并有最多同时激活 3 个应用等限制；AltStore/SideStore 本身也可能占一个名额。自动刷新有运行和网络条件，不是永不过期。可参考 [AltStore 免费账号说明](https://faq.altstore.io/altstore-classic/your-altstore/your-apps)。

全能签使用的证书可能属于其他签名渠道，其有效期由证书和描述文件决定，不能统一说成“7 天”或“永久免费”。最终安装与续签指南必须根据你实际选用的证书补齐。当前阶段还没有做真机安装验收。
