# DengTa Home 2.10.71 · 界面、记忆与共同活动更新

2026-10-14。此测试版包含前端、Android 与后端修复。正式服务部署状态和设备验收分别记录，源码推送不能替代服务验收。

## 本次变化

- 应用图标采用简洁的聊天气泡与星光；日记、记忆页面增加海岸灯塔插画，调整日夜文字对比。聊天页恢复展开状态下的彩虹胶囊入口，保留原彩色气流互动。
- 太阳绘图使用定位天气中的日出、日落时间，日落后隐藏太阳；小雨、普通雨和强降水使用不同雨量密度。天气与定位缓存按账号授权读取，撤销定位立即清除显示；新地点天气失败时不沿用旧地点天气。
- 调整功能导航、设置分类、对话输入与错误恢复入口；图片预览独立显示，支持 Escape、键盘焦点返回，账号或伴侣改变时关闭旧预览。
- 修复歌曲导入到 MCP 设置的导航，增加歌曲分析状态核对、音乐片段卡和共同故事章节；播放、共看、导入、画室、日记及记忆读取采用更明确的等待与失败反馈。
- 后端上下文预算按各接口实际序列化后的请求估算，减少规划阶段可通过、发送阶段却超限的差异；保留当前输入与用户个性化内容。
- 歌曲分析和扫码连接补充账号、伴侣隔离；图片生成与内容导入补充并发占用及结果核对，避免重复调用和跨范围回执。
- 后端 proxy-addr 更新到 2.0.8；其余没有兼容补丁的依赖问题仍需持续审查。
